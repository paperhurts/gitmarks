First-time setup — two things to create on GitHub
  1. Create a private repo to hold your bookmarks (the link pre-fills it).

    Any repo works — bookmarks live in a bookmarks.json gitmarks creates on first save, so an existing repo is fine too.

  2. Create a fine-grained access token scoped to just that repo:

    Repository access → Only select repositories → your bookmarks repo.
    Permissions → Repository permissions → Contents: Read and write. Nothing else.
    When the token expires, generate a new one and paste it below.

  3. Paste the token below with your GitHub login and repo name, then Validate and Save.

Links shared from social posts or newsletters often carry tracking parameters that identify who shared them. Stripping these means the same article saved from two sources becomes one bookmark, not two.
